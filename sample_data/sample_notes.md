# BFlux Review Sample Dataset

The full sample SQLite database is not stored directly in the GitHub repository because it is too large for normal GitHub file limits.

Download the review database from the GitHub Releases page.

Place the file here:

sample_data/bflux_review_sample.sqlite

Then run:

python bank_flux.py --sample

Suggested review commands:

full
forecast calibrated global
forecast USA
forecast timeline USA
scenario USA rate_shock
scenario global banking_shock
crises
case USA 2008
backtest crises
audit USA
compare USA CHN CHE MEX
